- Middleware keycloak-admin-allowlist ipAllowListс sourceRange: [192.0.2.0/24] т.е. фактически в ui admin панель зайти не может никто.  Изнутри кластера все работает т.к оператор ходит напрямую, минуя Traefik, поэтому все работает.

Скачать конфигурацию реалмов в json-формате: 

JSON попадают в `realms/` — эта папка в git не попадает
```bash
# получение адреса сервиса и запись его в переменную 
IP=$(kubectl -n keycloak get svc keycloak-service -o jsonpath='{.spec.clusterIP}')
# получение токена для авторизации и запись его в переменную
TOKEN=$(curl -s -X POST \
  -d 'grant_type=password&client_id=admin-cli&username=admin&password=keycloak' \
  "http://$IP:8080/realms/master/protocol/openid-connect/token" \
  | sed 's/.*access_token":"\([^"]*\)".*/\1/')

curl -s -X POST -H "Authorization: Bearer $TOKEN" \
  "http://$IP:8080/admin/realms/platform/partial-export?exportClients=true&exportGroupsAndRoles=true" \
  -o realms/platform-realm.json
```
Сlient secret приходит замаскированным, паролей пользователей в ответе нет
